## Faya Mask – Sales, Profit & Forecast Analysis (Power BI) ![Faya Mask Logo](https://github.com/Gtemowo/Faya-Mask-sales-profit-and-forecast-analysis/blob/main/Screenshot%202026-09-22%20112417.png)

## Project Overview
An end-to-end retail analytics dashboard built for Faya Mask, covering sales performance, profitability, customer segmentation, and 12-month forecasting. The report is structured as a guided analytical narrative across 9 pages, moving from a high-level overview to diagnostic deep-dives and forward-looking projections.

## Report Structure
- Introduction	Project framing and objectives
- Overview	Executive summary of key business metrics
- Sales Analysis	Total sales by customer segment, payment mode, day, channel, and product category
- Profit Analysis	Gross/net profit, discounts, expenses, profit margin, and charity aid tracking
- Segment Analysis	Sales & profit performance broken down by customer segment
- Sales Diagnostic Analysis	Month-over-month waterfall analysis of sales increases/decreases by channel, category, segment, and payment mode
- Forecast Analysis	12-month forecasts for gross sales, profit, expenses, and growth by segment
- Findings	Key takeaways from the analysis
- Recommendations	Actionable business recommendations

## Key Visuals & Techniques
- KPI cards for Net Sales, Gross Sales, Total Profit, Profit Margin, and Charity Aid
- Waterfall charts to diagnose month-over-month sales drivers
- Time-series forecasting (12-month projection) using Power BI's built-in forecasting
- Custom visuals: Multi-KPI, Two-Axis Bar Chart, Text Filter

## Tools Used
- Power BI Desktop (data modeling, DAX, report design)
- Power Query (data transformation)
- Custom Power BI visuals (AppSource)
